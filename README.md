## 💰 Salary Prediction Using Machine Learning

## 📌 Project Overview

This project predicts an individual's estimated salary using Machine Learning regression techniques.

The model uses personal, educational, and professional information such as:

- Age
- Gender
- Education Level
- Job Title
- Years of Experience

The project follows an end-to-end Machine Learning workflow, including data preprocessing, exploratory data analysis, model training, model evaluation, model saving, and Streamlit application integration.

---

## 🎯 Objectives

- Analyze and understand the salary dataset.
- Clean and preprocess the available data.
- Convert categorical features into numerical form.
- Perform Exploratory Data Analysis (EDA).
- Train and compare different regression models.
- Evaluate models using R² score and cross-validation.
- Select the best-performing model.
- Develop a Streamlit application for salary prediction.

---

## 📊 Dataset

The dataset contains salary-related information with the following features:

| Feature | Description |
|---|---|
| Age | Age of the individual |
| Gender | Gender category |
| Education Level | Educational qualification |
| Job Title | Professional job role |
| Years of Experience | Total work experience |
| Salary | Target variable |

### Dataset Summary

- Original records: **375**
- Records after removing missing values: **373**
- Total features: **6**
- Target variable: **Salary**
